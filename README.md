# 隐藏人设测试 · 测出你的隐藏人设

付费移动端 H5 娱乐测验。18 道原创 Likert 题，六维画像匹配 12 种隐藏人设。

## 在线地址

https://zengpenghui420-glitch.github.io/hidden-persona/

## 产品要点

| 项 | 说明 |
|---|---|
| 题目 | 18 题 · 五级自评（完全不像我 → 非常像我） |
| 维度 | 面具厚度 / 嘴硬锋利 / 内耗电压 / 行动迟滞 / 关系黏性 / 抽象电压 |
| 结果 | 主导人设 + 匹配度 + 六维雷达 + 特征表现 + 相处/自处建议 |
| 解锁 | 小红书订单号。到「我的订单」复制，每个订单号最多 3 次 |
| 扣次 | 首次开始答题扣 1 次；中途刷新、继续本次、结果刷新不扣；重新测试再扣。第 4 次拒绝并保留原结果 |
| 说明 | 只做订单号格式、绑定和次数控制，不校验、也不表示已经付款 |
| 重新测试 | 同一订单号再扣 1 次后重开本次测验 |
| 查看上次 | 仅读本机缓存，不扣次 |

已发出的访问码仍按原 vault 接口核销（`POST /redeem`、`GET /get`，quiz 为 `sbti`），页面不提示该入口。
