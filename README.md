# 隐藏人设测试 · 测出你的隐藏人设

付费移动端 H5 娱乐测验。18 道原创 Likert 题，六维画像匹配 12 种隐藏人设。

## 在线地址

https://zengpenghui420-glitch.github.io/hidden-persona/

## 产品要点

| 项 | 说明 |
|---|---|
| 题目 | 18 题 · 五级自评（完全不像我 → 非常像我） |
| 维度 | 面具厚度 / 嘴硬锋利 / 内耗电压 / 行动迟滞 / 关系黏性 / 抽象电压 |
| 结果 | 主导人设 + 匹配度 + 六维雷达 + 特征表现 + 相处/自处建议 |
| 解锁 | 小红书订单号。到「我的订单」复制。只接受 `P` + 18 位；重复块、逐位 ±1、以及 19 位都提示「订单号格式不对」，不开始测验 |
| 开始 | 格式通过后立刻开始。没有服务器绑定、限流，也不再向订单接口要剩余次数 |
| 提示 | 第一次开始：「验证成功，还可以测 2 次」。重新测试依次变为「还可以测 1 次」，然后「这是最后一次」 |
| 不改提示 | 刷新、继续本次、结果恢复、查看上次结果都不改这个提示 |
| 三次之后 | 同一订单号仍可进入，提示「验证成功」。格式正确的订单号不会出现「次数已经用完」或「暂时验证不了」 |
| 说明 | 订单号只做格式检查，页面不为订单号请求 `*.vercel.app`，也不表示已经付款 |
| 重新测试 | 同一订单号重开本次测验，并前进上面的提示 |
| 查看上次 | 仅读本机上次结果，不改提示 |

已发出的访问码仍按原 vault 接口核销（先 `POST /redeem`，`GET /get` 只读，quiz 为 `sbti`），页面不提示该入口。次数以 vault 返回的剩余次数为准。
